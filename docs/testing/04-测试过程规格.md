# add 测试过程规格

## 1. 测试过程

### PROC-001 测试准备

| 字段 | 内容 |
| --- | --- |
| 测试目标 | 确认被测应用入口、关键控件和测试依赖已具备可测试条件。 |
| 优先级 | P0 |
| 执行用例 | TC-ADD-024 |
| 启动条件 | 项目代码已就绪；被测页面或服务入口存在；测试工具可访问项目目录。 |
| 停止条件 | 被测入口无法访问、页面标题不正确或关键元素不可定位时停止，并记录阻断原因。 |
| 证据要求 | 测试报告、失败时截图或追踪文件 |
| 自动化方式 | 测试脚本 |
| 执行步骤 | 确认 index.html 文件存在、使用浏览器打开 index.html（文件协议或本地服务器）、确认页面标题显示"加法器"、确认有两个输入框（id=a 和 id=b）、确认结果区显示 0 |

### PROC-002 功能测试

| 字段 | 内容 |
| --- | --- |
| 测试目标 | 验证功能测试覆盖的测试用例均按预期执行，并留下可追踪证据。 |
| 优先级 | P0 |
| 执行用例 | TC-ADD-001、TC-ADD-002、TC-ADD-003、TC-ADD-004、TC-ADD-005、TC-ADD-006、TC-ADD-007、TC-ADD-008、TC-ADD-009、TC-ADD-010、TC-ADD-011、TC-ADD-012、TC-ADD-013、TC-ADD-024 |
| 启动条件 | 测试准备已完成；被测页面或服务入口可访问；测试脚本和依赖已就绪。 |
| 停止条件 | 全部执行用例完成；若关键用例失败、页面崩溃、关键元素不可定位或严重错误出现，则停止并记录缺陷。 |
| 证据要求 | 测试报告、失败时截图或追踪文件 |
| 自动化方式 | Playwright 测试脚本 |
| 执行步骤 | 按 TC-ADD-001 至 TC-ADD-009 执行正常相加功能测试、按 TC-ADD-010 至 TC-ADD-013 执行错误输入测试、按 TC-ADD-024 执行页面直接打开测试、记录每条用例的实际输出与预期是否一致 |
