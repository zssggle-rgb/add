## 4. 阻断规则样例

以下候选用例如果由模型生成，应被测试用例门禁阻断：

| 候选用例 | 阻断原因 |
|----------|----------|
| `5.` + `3` 结果显示 `8` | 与 `index.html:184-185` 完整消耗规则冲突 |
| `1e5` + `2` 结果显示 `100002` | 与 `docs/software-design/deep-design.md:262` 范围约束冲突 |
| 为 API 生成接口测试 | 项目无后端/API 测试依据 |
| 为性能生成阈值测试 | 无性能需求、无阈值、无测试环境依据 |
