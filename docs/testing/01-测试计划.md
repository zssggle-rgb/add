## 2. 适用测试类型

| 测试类型 | 说明 |
| --- | --- |
| 功能 | 适用 |
| 界面交互 | 适用 |
| 可访问性 | 适用 |
| 响应式 | 适用 |

## 3. 不适用测试类型

| 测试类型 | 原因 |
| --- | --- |
| unit | 单HTML页面无独立模块/类，单元测试不适用 |
| 接口 | 纯前端单文件，无API接口 |
| 集成 | 无多模块交互，纯单文件应用 |
| 性能 | 单HTML文件无性能测试需求 |
| 安全 | 无服务端、无数据持久化，攻击面极小 |

## 4. 完成准则

测试方案结构化门禁通过，测试用例规格具备 source_refs、oracle 和双向追踪关系；测试脚本生成后由测试用例检查任务验证 case_id 覆盖。
