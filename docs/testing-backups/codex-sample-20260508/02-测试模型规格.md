## 3. 测试模型

### 3.1 合法输入等价类

| 覆盖项 ID | 等价类 | 代表值 | 预期 | 追踪依据 |
|-----------|--------|--------|------|----------|
| CI-CALC-001 | 正整数 + 正整数 | `3`, `5` | `8` | TB-MATRIX-001 |
| CI-CALC-002 | 负数 + 正数 | `-3`, `5` | `2` | TB-MATRIX-002 |
| CI-CALC-003 | 小数 + 小数 | `1.5`, `2.5` | `4` | TB-MATRIX-003 |
| CI-CALC-004 | 空 + 数字 | ``, `5` | `5` | TB-MATRIX-004 |
| CI-CALC-005 | 数字 + 空 | `3`, `` | `3` | TB-MATRIX-005 |
| CI-CALC-006 | 空 + 空 | ``, `` | `0` | TB-MATRIX-006 |

### 3.2 非法输入等价类和边界值

| 覆盖项 ID | 输入类型 | 代表值 | 预期 | 追踪依据 |
|-----------|----------|--------|------|----------|
| CI-VALID-001 | 非数字字符 | `a`, `5` | 错误状态 | TB-MATRIX-007 |
| CI-VALID-002 | 重复负号 | `--5`, `3` | 错误状态 | TB-MATRIX-008 |
| CI-VALID-003 | 多个小数点 | `1..2`, `3` | 错误状态 | TB-MATRIX-009 |

| CI-VALID-005 | 单独小数点 | `.`, `3` | 错误状态 | TB-CODE-001 |
| CI-VALID-006 | 科学计数法输入 | `1e5`, `2` | 错误状态或范围外说明 | TB-SCOPE-001 |

### 3.3 `validate(value)` 决策表

| 条件/动作 | 空字符串 | 正则失败 | 正则通过但 NaN | 前缀解析 | 完整合法数字 |
|-----------|----------|----------|----------------|----------|--------------|
| `value === ''` | 是 | 否 | 否 | 否 | 否 |
| `VALIDATION_REGEX.test(value)` | 不适用 | 否 | 是 | 是 | 是 |
| `parseFloat(value)` 为 NaN | 不适用 | 不适用 | 是 | 否 | 否 |
| `String(parsed) === value` | 不适用 | 不适用 | 否 | 否 | 是 |
| 预期结果 | 合法 | 非法 | 非法 | 非法 | 合法 |
| 覆盖项 | CI-CALC-004..006 | CI-VALID-001 | CI-VALID-005 | CI-VALID-004 | CI-CALC-001..003 |

### 3.4 状态迁移模型

| 状态 ID | 状态 | 进入条件 | 可见表现 |
|---------|------|----------|----------|
| S-NORMAL | 正常状态 | 页面加载或合法输入 | `#result` 显示数字，无 `.error` |
| S-ERROR | 错误状态 | 任一输入非法 | `#result` 显示 `×`，输入框和结果区有错误样式 |
| S-RECOVERED | 恢复状态 | 错误后修正为合法输入 | 错误样式清除，显示正确结果 |

| 转换 ID | 起点 | 事件 | 终点 | 覆盖项 |
|---------|------|------|------|--------|
| TR-001 | S-NORMAL | 输入非法字符 | S-ERROR | CI-VALID-001 |
| TR-002 | S-ERROR | 修正为合法数字 | S-RECOVERED | CI-STATE-001 |
| TR-003 | S-RECOVERED | 再次输入非法格式 | S-ERROR | CI-VALID-002..005 |

## 4. TBD 和不进入正式清单的项

| 项 | 原因 | 处理 |
|----|------|------|
| 科学计数法成功计算 | 产品范围明确不支持 | 不生成成功用例；仅保留负向验证 |
| 性能压测 | 无性能需求、无工具链、无阈值来源 | 不进入正式测试用例 |
| 安全扫描 | 无服务端、无认证、无扫描需求 | 不进入正式测试用例 |
| 多浏览器认证 | 需求只要求本地浏览器打开 | 不进入当前正式清单 |
