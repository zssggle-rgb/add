## Problem Statement

需要一个简洁高效的 Web 版加法器，有两个输入框，输入数字后实时显示相加之和。

---

## What Makes This Cool

实用工具的核心价值：用起来顺手，看起来干净。一个加法器应该让人觉得"就该是这样"，而不是"凑合能用"。

---

## Constraints

- 单 HTML 文件（所有代码在一个 `.html` 中）
- 纯 HTML/CSS/JS，无框架、无依赖
- 无服务端，纯前端，文件可直接双击在浏览器打开
- local_only CI，不使用 GitHub CI 作为门禁

---

## Premises

1. **单文件架构** — HTML + CSS + JS 在一个 `.html` 文件中，无需构建工具
2. **纯原生 Web** — 无框架、无 npm、无依赖，文件可双击直接运行
3. **实时计算** — 输入即计算，无需点击按钮确认
4. **local_only CI** — 人工验收，不依赖自动化 CI

---

## Approaches Considered

### Approach A: 极简风格

- **Summary:** 两个输入框 + 结果显示，最少代码
- **Effort:** S
- **Risk:** Low
- **Pros:** 文件最小（< 5KB），加载最快，最易维护
- **Cons:** 视觉朴素，无交互反馈，边界情况无处理

---

### Approach B: 精致实用风格（推荐）

- **Summary:** 在极简基础上增加微交互和边界处理
- **Effort:** M
- **Risk:** Low
- **Pros:**
  - 输入框 focus 效果，视觉焦点清晰
  - 非法输入（字母、符号）时显示错误提示
  - 空输入按 0 处理，结果平滑过渡
  - 用户体验流畅，实用工具的基本尊严
- **Cons:** 代码量稍多（预计 8-12KB）

---

## Recommended Approach

**采用 Approach B：精致实用风格**

在保持单 HTML、纯 HTML/CSS/JS、无框架约束下，加入以下交互：

1. **Focus 效果** — 输入框获得焦点时有边框高亮
2. **实时计算** — `input` 事件触发，每次击键实时计算
3. **非法输入处理** — 非数字字符输入时显示错误提示，结果区红色提示
4. **空值按 0 处理** — 空输入视为 0，不报错
5. **平滑过渡** — 结果变化时有轻微过渡动画

---

## Visual Design Direction

- **风格：** 简洁现代、留白充足
- **配色：** 中性灰底 + 深色文字 + 蓝色 accent（与浏览器默认表单风格协调）
- **字体：** 系统字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif）
- **布局：** 垂直居中，单列，最大宽度 400px

---

## Component Inventory

### 输入框 (Input A, Input B)

- **Default:** 浅灰边框，white 背景
- **Focus:** 蓝色边框高亮，浅蓝阴影
- **Error:** 红色边框，错误提示文字
- **Disabled:** 不适用（本项目不需要）

### 结果显示区

- **Default:** 显示计算结果，字体较大
- **Error:** 红色文字 + 错误图标
- **Empty:** 显示 "=" 和占位符

---

## Technical Approach

- **文件结构：** 单 `index.html`，内嵌 `<style>` 和 `<script>`
- **事件绑定：** `input` 事件监听，实时计算
- **计算逻辑：**
  - `value = parseFloat(input.value) || 0`
  - `result = (a || 0) + (b || 0)`
- **非法输入：** 正则 `/^-?\d*\.?\d*$/` 检测，非数字时显示错误；额外用 `parseFloat()` 验证解析结果，若为 `NaN` 则触发错误状态（处理 `--5`、`1..2` 等正则匹配但解析失败的边界情况）
