## 本轮范围

### 交付范围

- 新增第 3 个输入框（C）
- 横向扩展布局：A + B + C = result
- 保持实时计算能力
- 保持输入校验（正则 + parseFloat 双重验证）
- 空输入按 0 处理

### 不做范围

- 不支持 4 个或更多数字相加
- 不支持历史记录/记忆功能
- 不支持科学计算模式
- 不添加自动化测试

## 架构与数据流

| 维度 | 状态 | 说明 |
|------|------|------|
| 架构模式 | 单文件HTML | 内联CSS+JS，无构建工具 |
| 数据流 | 同步实时计算 | input→validate→calculate→showResult/error |
| 无状态 | 是 | 纯前端，无持久化 |
| 边界风险 | **低** | 全部为同步DOM操作 |

**架构：无问题。**

## 实现顺序

```
Step 1: HTML结构增量（input#c + span.operator）
Step 2: DOM引用 const inputC = getElementById('c')
Step 3: calculate(a,b,c) 扩展
Step 4: showResult/showError inputC同步
Step 5: handleInput 三值联合校验
Step 6: inputC事件监听
```
