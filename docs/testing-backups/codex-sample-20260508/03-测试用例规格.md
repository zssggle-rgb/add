## 1. 用例字段规则

每条正式用例必须包含：

- `case_id`：稳定唯一编号。
- `coverage_item_ids`：来自测试模型的覆盖项。
- `test_basis_ids`：来自需求、设计、源码或风险依据。
- `source_refs`：具体文件位置。
- `oracle`：预期结果来源，不能只写模型推断。
- `technique`：测试设计技术。
- `preconditions`、`inputs`、`steps`、`expected_result`。

## 3. 明确不生成的用例

| 候选项 | 不生成原因 |
|--------|------------|
| `5.` + `3` 应显示 `8` | 与源码完整消耗规则冲突 |
| `1e5` + `2` 应显示 `100002` | 与产品范围冲突 |
| 性能阈值用例 | 无测试依据和完成准则 |
| 安全扫描用例 | 无安全测试范围、工具和风险级别 |
