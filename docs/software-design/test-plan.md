## 测试范围

- 验证加法器从 2 个输入扩展到 3 个输入后的核心计算能力。
- 验证空值、负数、小数、非法输入和错误恢复。
- 验证焦点、错误、响应式和无障碍相关交互状态。
- 回归验证原有 A+B 场景不会被破坏。

## 关键交互验证

### 功能验收（AC1-AC6）
- 输入 A=1, B=2, C=3 → 结果显示 `6`
- 输入 A=空, B=2, C=3 → 结果显示 `5`（空按 0 处理）
- 输入 A=1.5, B=2.5, C=3 → 结果显示 `7`
- 输入 A=-3, B=5, C=2 → 结果显示 `4`
- 输入任意非法字符（如 `abc`）→ 显示错误状态 `×`
- 三框全空 → 结果显示 `0`

### 错误处理验证
- 输入 `--5` → 显示错误状态（双重验证过滤）
- 输入 `1..2` → 显示错误状态（双重验证过滤）
- 输入 C 非法（AB 合法）→ inputC 显示红色边框 + result 显示 `×`
- 输入 A/B 非法（C 任意）→ 对应输入框显示红色边框 + result 显示 `×`

### 回归验证（REG1-REG4）
- 原有 A+B 功能正常（A=3, B=5 → 8）
- 输入 C 非法（AB 合法）时报错
- 输入 A/B 非法（C 任意）时报错
- 修复错误后结果正常显示

## 边界条件
- 浮点精度：0.1 + 0.2 + 0.3 → 0.6（无精度丢失）
- 极大值：999999 + 999999 + 999999 → 2999997（无溢出）
- 负数极值：-999999 + (-999999) + (-999999) → -2999997
- 双空输入 → 结果 `0`
- Tab 导航焦点切换 → Focus 样式（蓝色边框 + 阴影）
- 移动端 480px viewport → 布局不溢出
- 超小屏幕 320px viewport → 布局不溢出
- 键盘全操作可访问性

## 视觉状态验证
| 状态 | 预期效果 | 验证方法 |
|------|---------|---------|
| Focus | 蓝色边框 + 阴影 | 点击 inputC |
| Error | 红色边框 + 微红背景 | 输入 `abc` |
| Error 抖动 | shake 动画 300ms | 输入 `abc` 后观察 |
| × 图标 | 错误时显示 | 输入 `abc` 后检查 |

## 关键路径
- 正常加法：输入 → validate() → parseFloat → calculate(A,B,C) → showResult(结果)
- 错误恢复：非法输入 → showError() → 修改为合法 → showResult(结果)
- 空值处理：空输入 → validate('')=true → parseFloat('')=NaN → isNaN 检查 → 视为 0

## 通过标准

- 所有功能验收和回归验证均通过。
- 非法输入必须出现错误提示，修正为合法输入后必须恢复正常结果。
- 桌面和移动端布局均不溢出。
- 测试失败时进入缺陷管理，不在测试计划中直接改范围。
